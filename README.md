# Messagerie sécurisée post-quantique

Messagerie chiffrée résistante aux attaques quantiques, basée sur les algorithmes 
standardisés par le NIST.

## Stack
Kyber-768 (échange de clés), Dilithium-3 (signature), liboqs, Python/C

## Fonctionnalités
- Chiffrement des échanges avec encapsulation de clé Kyber-768
- Authentification forte des messages via signatures Dilithium-3
- Protocole de validation chiffré (ACK) détectant interception et suppression de messages
